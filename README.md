# 日本語初歩: грамматика, кандзи и слова без многочасовой зубрёжки

Материалы по учебнику «日本語初歩» (Japan Foundation, 34 урока) и пособию Пряхиной и Моргун
«Грамматика японского языка для студентов 1 курса». Задача: закрыть пробелы и дойти до
автоматизма за короткие ежедневные занятия, попутно тренируя аудирование и говорение.

| Что | Где | Зачем |
|---|---|---|
| **Тренажёр** | сайт [vioriah.github.io/-](https://vioriah.github.io/-/), [версия на claude.ai](https://claude.ai/artifact/KFugmLbeZRYQyeFzP2FKXf) или `trainer/index.html` | встроенная колода с интервальным повторением, формы глаголов, частицы, перевод вслух, диктант, чтение кандзи, разговор с Claude |
| **Колода Anki** | `anki/nihongo_shoho.apkg` | слова (1183), кандзи (383), фразы (224) с озвучкой: интервальное повторение |
| **Грамматика как система** | [`grammar/grammar_system.md`](grammar/grammar_system.md) (и вкладка «Карта грамматики» в тренажёре) | вся грамматика 34 уроков в одной схеме, а не 34 отдельные темы |
| Данные | `data/`, `grammar/sentences.tsv` | исходники колоды и тренажёра, можно править |

## 1. Как заниматься: 40–50 минут в день, кусками по 10–15

Работает не количество часов, а **ежедневность + активное вспоминание + речь вслух**.
Делите занятие на короткие блоки и привязывайте их к тому, что вы и так делаете каждый день.

| Когда | Что | Время |
|---|---|---|
| Дорога / утро | Anki на телефоне: сначала повторения, потом новые карточки | 15 мин |
| Перерыв | Тренажёр: «Формы» (30 ответов) + «Частицы» (15–20) | 10 мин |
| Вечер | «Скажи» вслух (10 фраз) + «Слушай» (5 фраз) | 10 мин |
| 2–3 раза в неделю | «Собеседник»: один короткий разговор на тему недели | 10–15 мин |
| Перед парой | Раздел «Карты грамматики» к текущему уроку | 5 мин |

Если день совсем плохой — сделайте **только повторения в Anki**. Пропуск одного дня не страшен,
пропуск недели обнуляет темп: повторения копятся.

### План догоняния

1. **Неделя 1 — увидеть систему.** Прочитайте «Карту грамматики» целиком (два захода по 30 минут).
   Цель — не выучить, а понять, на какой из восьми вопросов отвечает каждая конструкция (§0).
   Отмечайте строки, которые не узнаёте: это и есть ваши пробелы.
2. **Недели 1–4 — догнать пройденное.** В тренажёре выберите уроки «1 – (последний пройденный в вузе)».
   В Anki учите слова и кандзи этих уроков в первую очередь (см. «Старт с нужных уроков» ниже).
   Уже известное отвечайте кнопкой «Легко» — такие карточки быстро уходят из ротации.
3. **Дальше — идти вровень с группой.** Перед каждым новым уроком в вузе: его фразы в Anki,
   его конструкции в тренажёре, раздел карты грамматики. После урока — «Собеседник» на эту тему.

Новых карточек в день: **20–30 слов, 10–15 кандзи, 8–10 фраз**. Это примерно 15 минут
повторений через пару недель. Больше брать не стоит: через неделю повторения станут неподъёмными.

## 2. Тренажёр

Откройте [опубликованную версию](https://claude.ai/artifact/KFugmLbeZRYQyeFzP2FKXf) (работает и на телефоне)
или файл `trainer/index.html` в браузере. Вверху задайте диапазон пройденных уроков: слова,
предложения и формы берутся только из него.

| Режим | Что тренирует |
|---|---|
| **暗記 Карточки** | Та же колода, что в Anki (слова, кандзи с анимацией порядка черт, фразы), прямо в браузере: оценки «Снова / Трудно / Хорошо / Легко», интервалы как в Anki, лимит новых карточек в день, новые — по порядку уроков из выбранного диапазона. Прогресс: в версии на claude.ai — в вашем аккаунте Claude (виден на всех устройствах), на сайте — в браузере; кнопка «Сохранить прогресс в файл» переносит его между устройствами. Учите либо здесь, либо в Anki — прогресс у них раздельный. |
| **活用 Формы** | Глагол или прилагательное → нужная форма (ます, ない, て, た, ば, たら, потенциальная, пассив, каузатив…). При ошибке показывает правило: «‑く → ‑いて», «похож на II группу, но это I группа». Это главный инструмент автоматизма: отвечайте быстро, не вспоминая таблицу. |
| **助詞 Частицы** | Предложения учебника с пропущенной частицей. После ответа — перевод, конструкция урока и роль частицы. |
| **話す Скажи** | Русская фраза → скажите по‑японски вслух → сверьтесь с ответом → повторите за озвучкой. Можно напечатать или надиктовать свой вариант и попросить Claude проверить: другие верные переводы тоже засчитываются. «Повторить позже» возвращает фразу через несколько заданий. |
| **聞く Слушай** | Диктант на слух: скорость 0.7 / 0.9 / 1.0, проверка совпадения. |
| **読む Чтение** | Слово с кандзи → напишите чтение. Закрепляет чтения прямо в словах учебника. |
| **会話 Собеседник** | Разговор с Claude по‑японски на выбранную тему в пределах пройденной грамматики. Ошибки исправляются одной строкой по‑русски; если не знаете, как сказать, — пишите по‑русски. Работает в версии на claude.ai и на сайте (см. ниже). |
| **地図 Карта грамматики** | Вся грамматика курса как одна схема. |

### Где открывать и что с Claude

| Где | Кто может открыть | «Собеседник» и проверка переводов |
|---|---|---|
| Сайт [vioriah.github.io/-](https://vioriah.github.io/-/) | любой, без регистрации | работают через посредника на Cloudflare (папка [`worker/`](worker/README.md)) на ключе владельца сайта: посетитель вводит **код доступа** в «Настройках» внизу страницы или открывает ссылку с `?code=…`. Модель Claude Sonnet 5.5, около 0,75 цента за реплику. Пока посредник не подключён (`PROXY_URL` пуст), посетитель может вставить свой ключ Anthropic API. Без Claude работают все остальные режимы. |
| [Версия на claude.ai](https://claude.ai/artifact/KFugmLbeZRYQyeFzP2FKXf) | вы; другим — через меню «Поделиться» | работают сразу, через аккаунт Claude того, кто открыл (с его разрешения и в его лимитах). Ключ не нужен. |
| Файл `trainer/index.html` | кто скачал | с ключом API посетителя (посредник принимает запросы только с адреса сайта) |

Подключение «как в артефакте» на обычном сайте невозможно: страница на claude.ai вызывает Claude через аккаунт
зрителя, а у чужого сайта такого доступа нет. Поэтому на сайте используется ключ API, спрятанный в посреднике.

**Включить сайт (один раз).** В репозитории: Settings → Pages → Source: **GitHub Actions**. После этого
каждый пуш, меняющий `trainer/index.html` или колоду, сам обновляет сайт (workflow `.github/workflows/pages.yml`).
Ключ API получают на [platform.claude.com](https://platform.claude.com) → API keys.

**Ввод японского.** На компьютере можно печатать латиницей: `taberu` сам превратится в たべる
(отключается в «Настройках»). На телефоне удобнее японская клавиатура — и её **микрофон**: так
режимы «Скажи» и «Собеседник» превращаются в тренировку говорения с распознаванием речи.

**Озвучка** использует синтез речи устройства. Если голоса нет: Android — «Настройки → Синтез речи →
японский язык», Windows — «Параметры → Время и язык → Речь → добавить японский», iPhone — обычно есть.

## 3. Anki

1. Установите [Anki](https://apps.ankiweb.net) (компьютер, бесплатно), AnkiDroid (Android, бесплатно) или AnkiMobile (iPhone).
2. Откройте `anki/nihongo_shoho.apkg` (двойной клик или «Файл → Импорт»). Появится колода `日本語初歩` с тремя подколодами.
3. Синхронизируйте через бесплатный аккаунт AnkiWeb, чтобы заниматься с телефона.

| Подколода | Карточки |
|---|---|
| **1 Слова** | «Понимание»: слово (кандзи, если они есть в курсе) → чтение, перевод, озвучка, разбор кандзи. «Говорение»: русский → скажите слово вслух. |
| **2 Кандзи** | «Узнавание»: знак → значение, онные и кунные чтения, слова из учебника с номером урока, порядок черт. «Написание»: значение и чтения → напишите знак на бумаге. |
| **3 Грамматика (фразы)** | «Скажи по‑японски»: русская фраза + конструкция → скажите вслух, затем повторите за озвучкой. «Аудирование»: только звук → поймите фразу. |

**Рекомендуемые настройки** (шестерёнка у колоды → «Параметры»): включите FSRS (Anki 23.10+),
желаемая запоминаемость 0.88–0.9; новых карточек в день — как в разделе 1; максимум повторений — 300.

**Старт с нужных уроков.** У каждой карточки есть метка урока (`日本語初歩::урок_05`).
«Обзор» → в поиске `tag:日本語初歩::урок_05` → выделить всё → «Карточки → Переместить» во временную колоду
или «Изменить порядок» (Reposition → 0), чтобы эти слова пришли первыми. Можно и наоборот: найти
поздние уроки и приостановить (Suspend) до момента, когда группа до них дойдёт.

**Если карточек слишком много.** Сначала приостановите «Говорение» и «Написание»:
в «Обзоре» найдите `deck:日本語初歩 card:2` → выделить всё → «Приостановить». Вернёте, когда
«Понимание» и «Узнавание» станут лёгкими. «Написание» оставьте, если в вузе пишут 書き取り.

**Озвучка в Anki** работает через голос устройства (теги TTS): на телефоне с японским голосом —
сразу, на компьютере — после установки японского голоса в системе.

## 4. Почему так (коротко)

* **Интервальное повторение** (Anki) показывает карточку в момент, когда вы почти забыли, — это
  самый дешёвый способ держать в памяти 1200 слов и 380 кандзи.
* **Активное вспоминание**: в каждом режиме вы сначала отвечаете сами, потом видите ответ.
  Перечитывание учебника создаёт иллюзию знания, вспоминание — знание.
* **Производство важнее узнавания.** Пассивно грамматику вы, вероятно, понимаете; автоматизм появляется,
  только когда вы сами строите формы и фразы — быстро и много раз. Поэтому «Формы» и «Скажи» — ядро.
* **Схема вместо списка тем.** Новая конструкция встаёт рядом с родственными (のに — рядом с が и ても),
  и её проще и выбрать в речи, и не перепутать.
* **Голос.** Всё, что вы говорите, произносите вслух; всё, что слушаете, повторяйте вслед (shadowing).
  Так одновременно растут аудирование, произношение и скорость речи.

**Дополнительное аудио на этом уровне** (по желанию): к «日本語初歩» выпускались кассеты с текстами уроков —
спросите на кафедре или в библиотеке; подкаст «Nihongo con Teppei for beginners» и курс NHK World
«Easy Japanese» — понятная речь для начинающих, хороша для фонового слушания и shadowing.

## 5. Что сделано с материалами

* **Кандзи** — 383 знака из таблицы 新出漢字表 (с. 391–392 учебника; в предисловии сказано «380»).
  Урок каждого знака — по таблице; 母 перенесён в урок 12, где он реально вводится. Онные и кунные чтения
  и все примеры сверены со словарями KANJIDIC2 и JMdict. Примеры — сначала слова из разделов «新しい漢字»
  самого учебника (с номером урока), затем частые слова для чтений, которых в учебнике нет.
* **Слова** — из присланного docx (1223 записи по урокам). Исправлены опечатки и ошибки перевода
  (например, ビール было «здание», ならう «платить» → はらう, ひげ «узы» → «усы», たいぶ → だいぶ,
  しょうひん «больница» → «приз»), добавлены написания кандзи и части речи. Кандзи на лицевой стороне
  карточки показываются, только если все знаки слова есть в курсе; иначе — кана, а полное написание на обороте.
* **Фразы** — 224 примера ко всем 文型 из перечня 主な文型・文法事項, с фуриганой.
* **Грамматика** — схема написана заново как система; номера уроков — по перечню в конце учебника.

## 6. Для правки и пересборки

```bash
pip install genanki                    # для колоды и тренажёра
python tools/build_anki.py             # → anki/nihongo_shoho.apkg
python tools/build_trainer.py          # → trainer/index.html (нужен pandoc)
python tools/check_kanji.py jamdict.db # сверка чтений с KANJIDIC2 (база из пакета jamdict-data)
pip install fugashi unidic-lite        # только если добавляете фразы:
python tools/add_furigana.py           #   фуригана для новых строк grammar/sentences.tsv
python tools/make_particle_slots.py    #   пропуски для режима «Частицы»
```

Повторный импорт пересобранной колоды в Anki обновляет карточки, не теряя прогресса.

Схемы порядка черт — [KanjiVG](https://kanjivg.tagaini.net) (© Ulrich Apel, CC BY‑SA 3.0), лежат в `data/kanjivg/`.
Чтения проверены по KANJIDIC2 и JMdict ([EDRDG](https://www.edrdg.org), CC BY‑SA 4.0).
