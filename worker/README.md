# Посредник для Claude на сайте

Сайт на GitHub Pages публичный: ключ API, положенный в его код, увидит любой посетитель.
Поэтому ключ хранится в секрете маленького сервера на Cloudflare Workers (бесплатный тариф:
100 000 запросов в день). Сайт шлёт запросы посреднику, посредник добавляет ключ и пересылает их в API.

Что посредник делает сам, независимо от того, что прислала страница:

- ставит модель `claude-sonnet-5-5` (переменная `MODEL`) и ограничивает длину ответа (`MAX_TOKENS`, по умолчанию 8000);
- принимает запросы только с адреса сайта (`ALLOWED_ORIGINS`);
- требует код доступа, если задан секрет `ACCESS_CODE`;
- с привязкой `LIMITER` пропускает не больше 10 запросов в минуту с одного IP.

## Развёртывание через сайт Cloudflare (можно с iPad)

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com).
2. **Compute (Workers) → Workers & Pages → Create → Start with Hello World**. Назовите воркер `shoho-claude` и нажмите **Deploy**.
3. **Edit code**: удалите весь код-заготовку и вставьте содержимое файла [`worker.js`](worker.js). Нажмите **Deploy**.
4. Вернитесь к воркеру: **Settings → Variables and Secrets → Add**.
   - Тип **Secret**, имя `API_KEY`, значение — ваш ключ API.
   - Тип **Secret**, имя `ACCESS_CODE`, значение — придуманный код (например, слово из 8+ букв).
     Без него любой, кто найдёт адрес посредника, сможет тратить ваш баланс через сайт.
   - Если ключ **не от Anthropic** (ключи Anthropic начинаются с `sk-ant-`): тип **Text**, имя `UPSTREAM`,
     значение — адрес API вашего сервиса, совместимый с Anthropic Messages API (без `/v1/messages` на конце).
     Его указывают в документации сервиса, где куплен ключ.
5. Скопируйте адрес воркера вида `https://shoho-claude.<ваше-имя>.workers.dev` (виден на странице воркера)
   и пришлите его — его нужно вписать в `PROXY_URL` в `trainer/template.html` и пересобрать сайт.

Проверка: откройте сайт, «Настройки» → код доступа → «Сохранить код», затем «Собеседник» → любая тема.
Друзьям можно дать ссылку `https://vioriah.github.io/-/?code=ВАШ_КОД#chat`: код сохранится в их браузере сам.

## Защита баланса

- Поставьте месячный лимит трат там, где куплен ключ (у Anthropic: platform.claude.com → Settings → Limits).
- Код доступа меняется в любой момент: новый секрет `ACCESS_CODE` → Deploy. Старые ссылки перестанут работать.
- Если ключ мог утечь, отзовите его и создайте новый, затем замените секрет `API_KEY`.

## Развёртывание из командной строки

```sh
cd worker
npx wrangler deploy
npx wrangler secret put API_KEY
npx wrangler secret put ACCESS_CODE
```

`wrangler.toml` уже содержит модель, адрес сайта и ограничение 10 запросов в минуту с одного IP.
